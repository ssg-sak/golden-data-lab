# CASE 02: Youth Migration & Regional Dynamics

## 1. Problem
- 청년은 어느 지역에서 빠져나가고, 어디로 이동하는가?
- 어떤 지역이 청년을 상대적으로 잘 유지하는가?

## 2. Data
- **출처:** 행정안전부 지역별 인구이동 Open API, KOSIS e-지방지표
- **설명:** 전입·전출 행정기관, 통계년월, 성별·만 나이별 이동 인구. 청년인구비율, 순이동 지표.
- **활용 요건:** 연령별(20~39세) 이동 차이, 수도권·비수도권 Flow 분석, 청년 정착/유출형 지역 분류 및 패널 분석

(이하 내용은 분석 진행 후 채워집니다.)

# 대구 공공보건 SQL 분석

검증된 정책 스냅샷을 관계형 데이터 모델로 적재하고, 행정동별 취약인구와 응급의료 접근성 차이를 SQL로 재검증하는 학습·분석 영역입니다.

## 현재 상태

스키마와 분석 쿼리는 아직 구현 전입니다. 빈 폴더는 다음 산출물의 위치를 미리 정의합니다.

```text
01_sql_public_health_analysis/
├── data/       # SQL 적재용 가공 데이터
├── queries/    # 스키마·적재·분석 쿼리
├── results/    # 재생성 가능한 쿼리 결과
└── docs/       # 데이터 모델과 검증 기록
```

## 예정 분석 질문

1. 취약인구가 많은 행정동은 어디인가?
2. 일반 차량 기준 최근접 기관 도로 ETA가 긴 지역은 어디인가?
3. 취약인구와 접근성 부담이 동시에 큰 지역은 어디인가?
4. 소아와 어르신 분석 모드의 후보 우선순위는 어떻게 다른가?
5. Python 정책 릴리스 집계와 SQL 결과가 일치하는가?

## 안전한 해석

분석 기관 분류와 일반 차량 ETA는 정책 비교용 입력입니다. 개별 병원의 진료 가능 여부, 환자 수용 가능 여부, 실제 구급차 이송시간을 의미하지 않습니다.

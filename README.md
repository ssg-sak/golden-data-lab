# Golden Data Lab 🔬

**Golden Data Lab**은 여러 도메인의 원천 데이터를 같은 분석 프레임으로 반복 처리하며, SQL·데이터 품질·Python·통계·Power BI·의사결정 제안까지 재현 가능하게 축적하는 개인 분석 실험실입니다.

## 한눈에 보기
- **목표 직무:** 주니어 데이터 분석가, 데이터 운영, BI, 공공/행정 데이터 분석
- **증명할 역량:** SQL → 데이터 품질 → Python EDA → KPI/통계 → BI 시각화 → 인사이트 → 재현성
- **운영 원칙:** 사례는 작게 완결하고 같은 분석 프레임을 반복합니다.

## 포트폴리오 역할 분담
| 프로젝트 | 핵심 역할 | 보여주는 역량 |
| --- | --- | --- |
| Golden Time / Golden Governance | 공공·행정 데이터 기반 대표 프로젝트 | GIS, 정책 분석, 서비스 구현, 깊이 |
| EV SafeCharge | 팀 데이터·AI 프로젝트 | 데이터 정의, 품질 관리, 모델 평가, 협업 |
| **Golden Data Lab (현재)** | 여러 도메인의 반복 가능한 분석 사례 모음 | SQL, Python, 통계, BI, 문서화의 반복 실행력 |

## 표준 분석 흐름
```text
Business Question → SQL Extraction → Data Quality Check → Python EDA → Statistical Analysis → KPI & Segmentation → Visualization (Power BI) → Insight & Action → Reproduction
```

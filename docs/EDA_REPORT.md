## 6. 해석 경계

- VDI는 `취약인구 × ln(1 + 일반 차량 도로 ETA)`의 구성 결과이므로 취약인구·ETA와 VDI의 상관을 독립적인 인과 발견으로 해석하지 않는다.
- 위험 기준 `13,261.43`은 현재 릴리스의 상위 분위수 기준으로 우선 검토 대상을 좁히는 값이며 의료 위험의 절대 경계가 아니다.
- 일반 차량 ETA는 실제 구급차 이송시간이나 병원의 수용 가능성을 뜻하지 않는다.
- 행정동 중심점, 기관 목록, 인구 기준월이 바뀌면 결과도 달라질 수 있다.
- 후보지와 자원배치 결과는 현장·예산·부지·의료인력 검토 전 단계의 비교 자료다.

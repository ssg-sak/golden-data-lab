# 데이터 계보와 분석 한계

## 계보

이 프로젝트는 대구 골든타임 저장소가 공개한 단일 `policy_release.json`을 분석 입력으로 사용합니다. 다운로드 시 고정 Git 커밋과 원시 파일 SHA-256을 함께 확인하여 파일이 바뀌거나 불완전하게 내려받아진 경우 분석을 중단합니다.

정책 릴리스 내부에는 행정동, 분석 대상 기관, 후보지, 후보 추적, 접근성 및 최적화 결과와 각각의 콘텐츠 해시가 포함됩니다. 노트북은 기본 계약인 150개 행정동, 25개 기관, 9개 후보, 5,100개 성공 경로와 0개 누락 경로를 먼저 확인합니다.

## 시간 기준

- 인구 기준월: 2026.06
- 정책 릴리스: 2026-07-18-r2
- 분석은 해당 검증본의 스냅샷을 설명합니다.
- 병상 등 운영 정보가 변해도 이 스냅샷의 정책 결과가 자동 변경되지는 않습니다.

## 해석 한계

- VDI는 취약인구와 일반 차량 도로 ETA를 결합한 상대 비교 지표입니다.
- 상위 분위수는 우선 검토 대상을 좁히는 규칙이지 위험의 절대 기준이 아닙니다.
- K-Means, p-median, MCLP 결과는 입력·후보군·가중치·거리 조건에 종속됩니다.
- 일반 차량 ETA는 실제 구급차 주행시간이나 환자 이송 성과가 아닙니다.
- 후보지는 신설 확정지가 아니며 예산, 부지, 의료인력, 행정·의료 전문가와 현장 검토가 필요합니다.

## 갱신 원칙

새 원천 데이터를 사용할 때는 기존 검증본을 덮어쓰지 않고 새 버전으로 분석합니다. 데이터 계약과 해시 검증, 결측·중복·이상치 점검, 결과 검토가 완료된 버전만 공개 분석에 사용합니다.
